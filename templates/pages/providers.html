Providers

Providers are Rho modules under providers/. Each one implements an interface, such as the alert interface's channels; an application that depends on a provider binds it in its module.yml. This page manages the installed provider set, the same way the Plugins page manages the installed plugins.

Install a provider

Clone a provider from a git URL, or install one that already exists on this machine. A provider is a module whose manifest lists the interface it implements.
